# Bandz HTF

Bandz HTF is a higher-timeframe market-context workspace designed to bring information normally checked across several charts directly onto an execution timeframe.

The projected HTF candle lanes display developing and completed higher-timeframe price action beside the live chart. Automatic range levels map the prior completed high, low, midpoint, and relevant quarter levels so traders can see where current price sits within the larger dealing range without switching timeframes.

Its intermarket-divergence module compares the active symbol with user-selected comparison markets. It marks cases where one market trades through a prior extreme while the comparison market does not confirm that move. The comparison symbols and individual timeframes remain configurable.

Bandz Rejection Zones look for liquidity sweeps followed by rejection behavior and preserve the resulting price area on the chart. These zones are intended to be evaluated together with HTF location and intermarket confirmation, not as standalone entry signals.

The HOD / MID / LOD dashboard adds intraday context by tracking the current trading-day range, midpoint position, and the times at which the daily extremes were established. Optional countdowns, sweep guides, labels, spacing, colors, and displayed candle groups can be adjusted from the indicator settings.

How the components work together:
1. Use the projected candles and previous-range levels to establish higher-timeframe location.
2. Watch prior highs, lows, midpoints, and quarter levels for liquidity interaction.
3. Use intermarket divergence as confirmation when enabled.
4. Use rejection zones to identify areas where swept liquidity was rejected.
5. Use the daily-range dashboard as an additional timing and location reference.

Bandz HTF is a discretionary context and confirmation tool. It does not place trades, generate guaranteed entries, or calculate performance. Developing candles and live divergence conditions can change before their periods close, comparison markets can have different sessions, and every signal should be evaluated with independent risk management.
